# Справочник маркетплейсов: Ozon, WB, Яндекс Маркет, Uzum

Зеркало лежит в `__MP_DOCS_ROOT__/mirror` — обычные markdown-файлы под git.
Сеть не нужна.

## Как искать

```bash
__MP_DOCS_ROOT__/bin/mpdocs search "posting/fbs/ship"      # поиск по всему зеркалу
__MP_DOCS_ROOT__/bin/mpdocs search "лимит" -g 'ozon/**'    # только Ozon
__MP_DOCS_ROOT__/bin/mpdocs status                         # что есть и когда обновлялось
__MP_DOCS_ROOT__/bin/mpdocs changelog                      # что маркетплейс объявил сам
__MP_DOCS_ROOT__/bin/mpdocs changes --since 1.month        # что реально изменилось
```

Или напрямую, если нужен полный контроль:

```bash
rg -n "нужная строка" __MP_DOCS_ROOT__/mirror
```

## Правила

- **Сначала зеркало, потом интернет.** docs.ozon.ru, dev.wildberries.ru и инструкция
  Uzum закрыты антиботом: обычный запрос оттуда вернёт капчу или 403, а тут ответ мгновенный.
  В сеть идти, только если зеркало пустое или вопрос про совсем свежее изменение.
- **Метод ищется по пути.** `mpdocs search "v3/posting/fbs/list"` найдёт файл метода;
  в его frontmatter есть `deprecated: true`, если метод доживает последние дни.
- **Спорные детали сверять со `spec.json`.** Markdown — читаемый срез с ограничением
  глубины вложенных схем; сырая спека полная.
- **Даты в базе знаний реальные.** Поле `updated` в frontmatter — дата правки на
  стороне маркетплейса, а не дата скачивания.
- **Проверить свежесть.** `mpdocs status` показывает дату последнего обновления.
  Если зеркалу больше недели — предупредить и обновить (см. ниже).

## Что изменилось у маркетплейса

Два разных вопроса, не путать:

- **что объявили** — `mpdocs changelog [-s ozon|wb|ym]`. Журналы есть у Ozon, WB и ЯМ:
  Ozon держит его прямо в спеке (тег `News`, вся история), ЯМ — в справке
  (`changelog/deprecated.md` особенно полезен), WB — на отдельной странице,
  и у него в зеркале только последние ~20 записей, скользящее окно.
  У Uzum журнала нет — его изменения видны только через `changes`.
- **что изменилось на самом деле** — `mpdocs changes --since 1.month`.
  Объявляют не всё: лимиты и схемы правят молча, git-история это ловит.

```bash
cd __MP_DOCS_ROOT__/mirror && git log -p --since=1.month -- ozon/api/seller/
```

## Обновление

```bash
git -C __MP_DOCS_ROOT__/mirror pull      # забрать свежий срез из общего зеркала
```

Это штатный способ: источник обновляет зеркало каждую ночь и пушит сам.
Если `mpdocs status` пишет, что зеркалу больше трёх дней, — сделать pull, прежде
чем отвечать на вопрос о свежих изменениях. Раз и навсегда:
`__MP_DOCS_ROOT__/install.sh --auto-update` поставит ежедневный pull в crontab. Качать самому (`mpdocs update`) можно только на машине, где
стоят requests, pyyaml и Camoufox: Ozon и WB отдают документацию исключительно
браузеру с резидентного IP. Яндекс Маркет и спека Uzum качаются напрямую и без
браузера: `mpdocs update ym uzum-api`. Инструкции Uzum (`uzum-kb`) нужен Camoufox,
но хватает и серверного IP.
